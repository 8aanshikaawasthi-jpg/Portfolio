# Anshika Awasti — Portfolio Website

A simple personal portfolio website built with **HTML** and **CSS**, using a green-themed design.

## Files

- `index.html` — Main portfolio page, including the introduction, about section, project tabs, and contact section.
- `style.css` — Styles for the layout, colors, typography, responsive design, and clickable project tabs.

## Projects

The portfolio currently features two project-preview tabs:

1. **Student Portal** — A school portal concept featuring student information, subject lists, links, and a registration form.
2. **Flexbox Quest** — A playful game-interface concept featuring player stats, inventory items, and quest-style panels.

These are preview cards only. You can connect each tab to its own deployed project later.

## Run Locally

1. Download `index.html` and `style.css`.
2. Put both files in the same folder.
3. Open `index.html` in a web browser.
4. Click the **Student Portal** and **Flexbox Quest** tabs to switch between project previews.

No build tools or installation are required.

## Customize

- Edit the text in `index.html` to update the portfolio content.
- Change colors, spacing, fonts, and responsive behavior in `style.css`.
- When your projects are deployed, add links or buttons to their live URLs in the relevant project panels.

## Deployment

You can deploy the website using any static-site host that supports HTML and CSS, such as GitHub Pages or Netlify. Upload both files while keeping their relative paths unchanged.

## Technologies
